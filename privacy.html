스공의 약속

스공은 사용자의 공부 데이터를 사용자의 소유로 생각합니다.

사용자가 기록한 공부 내용은 사용자의 기기 안에만 저장되며, 개발자가 수집하거나 열람하지 않습니다.

필요한 정보만 기기에 저장하고, 불필요한 수집은 하지 않는 것을 원칙으로 합니다.

1. 개인정보의 수집

현재 버전의 스공은 회원가입 및 로그인 기능을 제공하지 않으며, 다음과 같은 개인정보를 수집하지 않습니다.

  • 이름
  • 이메일 주소
  • 전화번호
  • 위치 정보
  • 연락처
  • 광고 ID
  • 기기 식별 정보
  • 결제 정보
  • 생체 정보

2. 앱에 저장되는 정보

사용자가 직접 입력한 다음 정보는 사용자의 기기 내부에만 저장됩니다.

  • 공부 기록
  • 과목
  • Focus
  • 목표 설정
  • 앱 설정

이 정보는 SQLite 및 SharedPreferences를 이용하여 사용자의 기기에만 저장되며, 외부 서버로 전송되지 않습니다.

개발자는 해당 정보를 수집하거나 열람할 수 없습니다.

3. 인터넷을 통한 정보 전송

현재 버전의 스공은 사용자의 공부 기록이나 설정 정보를 외부 서버로 전송하지 않습니다.

4. 제3자 제공

스공은 사용자의 정보를 제3자에게 제공하거나 판매하지 않습니다.

5. 광고 및 분석

현재 버전의 스공은 다음 기능을 사용하지 않습니다.

  • 광고 SDK
  • 사용자 행동 분석(Analytics)
  • 맞춤형 광고
  • 광고 ID 수집

향후 서비스 개선을 위해 이러한 기능이 추가되는 경우, 본 개인정보처리방침을 업데이트하여 변경 사항을 안내합니다.

6. 개인정보처리방침 변경

본 개인정보처리방침은 앱 기능 변경 또는 관련 법령의 개정에 따라 수정될 수 있습니다. 중요한 변경 사항이 있는 경우 최신 내용을 본 페이지를 통해 안내합니다.
